# video-audio-process-nextJs-gemma3-wisper
Audio Processor GM-Pro: Enhanced app for audio/video transcription using Whisper AI. Extracts &amp; converts audio to MP3/WAV/AAC/OGG. Adds normalization for consistent volume &amp; compression to reduce dynamic range. Offline, browser-based, private processing. Supports timestamps &amp; exports (TXT/JSON/SRT). Ideal for podcasts/videos
